The program has three main states: On the title page, in the level menu, and in level.


On the title page you can simply press play or exit. All variables should be in default state.

In the level menu you mainly choose what the active_level_number variable should be (by clicking a button).
Every other variable should be in default state.

At the beginning of in level it makes active_level to be according to the chosen active_level_number.
Then you can play the game. Here the variables evolve and the simulation runs.
If you go back to the level menu it should reset all variables to default state, except active_level_number.

Global variables and auxiliary functions

int main {

  Rendering stuff

  Declaration of all gui variables.

  Declaration of admin variables, those are for handling active level and menus.

      Polling events: detect keyboard and mouse events.

  }

  return 0;
